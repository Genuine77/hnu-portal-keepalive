湖南大学 校园网自动保活 v1.0.3（Windows 版）
================================================

怎么用
------
1. 双击 HNU-Portal.bat，弹出用户账户控制时选「是」
2. 输入 1，回车
3. 输入校园网账号，回车
4. 输入校园网密码（屏幕上不显示，正常现象），回车
5. 最后一行会显示当前网络状态，显示正常就装好了

装好之后
--------
系统每 2 分钟自动检测一次，掉认证会自动重新登录。
关掉窗口、退出登录、重启电脑都不影响，它是注册到 Windows 任务计划程序里的。

再打开这个 bat 可以：
  2 = 改账号或密码
  3 = 卸载（清理干净）
  4 = 查看重新认证记录（平时是空的，只有真掉线过才有内容）
  5 = 立刻检测并重连一次

装在哪
------
C:\ProgramData\HNU-Portal\
    keepalive.ps1    核心脚本
    user.txt         账号
    pass.txt         密码
    keepalive.log    日志（仅掉线时写入）
任务计划程序里的任务名：HNU Portal Keepalive

注意
----
- 这个 bat 只是安装器。装完之后删掉它不影响使用，但建议留一份方便以后改密码或卸载。
- 只在本人设备、本人账号上使用。
- 免安装、无依赖，不需要装 Python 或 PowerShell 模块（用系统自带的 PowerShell 5.1）。
